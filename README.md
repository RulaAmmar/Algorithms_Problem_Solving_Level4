# Date to Day Calculator (C++)

This is a simple **C++ program** that takes a date (day, month, year) from the user and calculates:
- The formatted date.
- The order of the day in the week (0–6).
- The name of the day (Sun, Mon, Tue, ...).

---

## 📌 Features
- Reads date input from the user.
- Prints the date in the format: `Day/Month/Year`.
- Calculates which day of the week the date falls on.
- Displays both the **order of the day** (0–6) and the **name of the day**.
